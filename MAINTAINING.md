# Maintaining this profile

The profile is the root README of the public jc80800/jc80800 repository.

## Add a project

1. Confirm the project or case study is already public and ready to share.
2. Choose Side quests (Play), Rabbit holes (Learn), or Allegedly useful (Build) by the visitor’s main reason to open it.
3. Replace that shelf’s italic placeholder with a project entry; templates are hidden in README comments.
4. Include a clear description, honest status, and only working links.
5. Keep each shelf to three highlighted entries. Add an archive page when needed.

Do not publish private repository names, internal company details, metrics, or links without deciding to share them.

## Design

Subway-inspired personal workshop; cream, charcoal, transit yellow and terracotta. NYC humor with readable, plain-language section descriptions. Keep navigation and essential information as text, outside the illustration.
